\section*{Введение}
Современный этап развития образования характеризуется активным внедрением цифровых технологий в учебный процесс. Особенно это актуально для дисциплин технического профиля, таких как информатика, где важную роль играет практическая подготовка студентов. Одной из ключевых проблем в обучении является недостаточная оснащённость лабораторной базы, что затрудняет освоение студентами аппаратных и программных аспектов дисциплины.

Целью данной курсовой работы является оптимизация учебного процесса по дисциплине Информатика за счёт разработки цифрового устройства для выполнения лабораторных работ. Это устройство призвано упростить проведение экспериментов и повысить наглядность изучаемых процессов.

Актуальность работы обусловлена необходимостью повышения качества практической подготовки студентов при ограниченных ресурсах. Использование специализированных цифровых устройств позволяет сделать лабораторные работы более доступными и интерактивными.

Практическая значимость заключается в возможности применения разработанного устройства в образовательных учреждениях для улучшения усвоения материала.

\subsection{Пользовательские сценарии}
Пользовательские сценарии описывают типовые ситуации взаимодействия студентов и преподавателей с платой в рамках учебного процесса.
Они охватывают:
\begin{enumerate}
    \item Базовые операции – изучение простых логических схем;
    \item Работа с элементами памяти - триггерами и регистрами;
    \item Комплексные задачи – реализация различных видов счетчиков.
\end{enumerate}

Сценарии построены по принципу от простого к сложному.
\begin{enumerate}

    \item Сценарий 1. Изучение базовых логических элементов.\\
    \begin{itemize}
        \item Действующие лица: Студент, Преподаватель;
        \item Цель: Освоить принципы работы булевых функций в базисе И, ИЛИ, НЕ.
    \end{itemize}
    \begin{itemize}
        \item Преподаватель объясняет теоретические основы булевой алгебры;
        \item Студент получает задание реализовать логическую функцию;
        \item С помощью макетной платы студент:
        \begin{enumerate}
            \item Находит нужные компоненты по маркировке;
            \item Соединяет элементы согласно схеме;
            \item Подключает источники сигналов и индикаторы.
        \end{enumerate}
        \item Студент проверяет работу схемы, сравнивая с таблицей истинности;
        \item Преподаватель проверяет результат.
    \end{itemize}

    \item Сценарий 2. Создание схемы на основе элементов памяти.\\
    \begin{itemize}
        \item Действующие лица: Студент, Преподаватель;
        \item Цель: Понять принципы работы триггеров.
    \end{itemize}
    \begin{itemize}
        \item Преподаватель объясняет теорию о триггерах;
        \item Студент получает задание собрать определенный регистр;
        \item С помощью макетной платы студент:
        \begin{enumerate}
            \item Находит и подключает триггеры;
            \item Подключает тактовый сигнал;
            \item Подключает индикаторы состояния.
        \end{enumerate}
        \item Студент проверяет работу схемы.
        \item Преподаватель проверяет результат.
    \end{itemize}  

        \item Сценарий 3. Разработка двоичного счетчика.\\
    \begin{itemize}
        \item Действующие лица: Студент, Преподаватель;
        \item Цель: Реализовать и проанализировать работу двоичного счетчика.
    \end{itemize}
    \begin{itemize}
        \item Преподаватель объясняет теорию о двоичных счетчиках;
        \item Студент получает задание собрать определенный счетчик;
        \item С помощью макетной платы студент:
        \begin{enumerate}
            \item Конфигурирует триггеры как счетные элементы;
            \item Организует цепи переноса;
            \item Подключает индикаторы и тактовый сигнал.
        \end{enumerate}
        \item Студент проверяет работу схемы.
        \item Преподаватель проверяет результат.
    \end{itemize}  
\end{enumerate}

Можно заметить, что все сценарии имеют одинаковый шаблон, что положительно сказывается на масштабировании учебного процесса.Каждый сценарий можно масштабировать по сложности в зависимости от уровня подготовки студентов и учебных задач.

Данные сценарии могут адаптироваться под конкретные учебные программы, обеспечивая гибкость и эффективность обучения. Их цель – развитие инженерного мышления у студентов через практический опыт.

Наименование темы разработки – «Разработка цифрового устройства для выполнения лабораторных работ».
\subsection{Назначение разработки}
Система будет использоваться в рамках лабораторных работ по дисциплине информатика двумя группами пользователей: студент и преподаватель.
\subsubsection{Функциональные требования}
\begin{enumerate}
    \item Базовые характеристики:
    \begin{itemize}
        \item Плата должна обеспечивать работу с комбинационными и последовательностными цифровыми схемами;
        \item Рабочее напряжение: 5В;
        \item  Габариты платы: не более 200×200 мм.
    \end{itemize}

    \item Логические элементы:
    \begin{itemize}
        \item НЕ (инверторы) - минимум 6 элементов;
        \item И - минимум 2 элемента;
        \item ИЛИ - минимум 2 элемента;
        \item Возможность каскадирования логических элементов;
        \item Наличие свободных элементов для реализации произвольных функций.
    \end{itemize}

    \item Последовательностные элементы:
    \begin{itemize}
        \item Минимум 3 независимых D-триггера;
        \item Возможность объединения в регистры;
        \item Возможность объединения в двоичные счетчики.
    \end{itemize}

    \item Компановка платы:
    \begin{itemize}
        \item Должно быть явно выделено 3 основных слоя: ввод данных, слой логики и вывод данных;
        \item Все логические контакты микросхем подключены к гребенкам для удобного соединения;
        \item Каждый логический контакт обязательно маркируется условным обозначением на основе документации по микросхеме.
    \end{itemize}
    
\end{enumerate}

\subsubsection{Эксплуатационное назначение}
Система будет использоваться в рамках лабораторных работ по дисциплине информатика для оптимизации учебного процесса.

\subsection{Требования к цифровому устройству}
В данном разделе будут описаны основные требования к цифровому устройству.
\subsubsection{Требования к составу выполняемых функций}
\begin{enumerate}
    \item Функция И - выполнение операций И над двоичными сигналами;
    \item Функция ИЛИ - выполнение операций ИЛИ над двоичными сигналами;
    \item Функция НЕ - выполнение операций НЕ над двоичными сигналами;
    \item Функция И, ИЛИ, НЕ - выполнение комбинированных операций в заданном базисе;
    \item Функция хранения бита информации - выполнение операции энергозависимого хранения бита информации;
    \item Функция хранения нескольких бит информации - выполнение операции энергозависимого хранения нескольких бит информации;
    \item Функция счета - выполнение операции по подсчету тактовых сигналов;
    \item Функция ввод - выполнение операций для подачи логических сигналов в слой комбиначионной схемы;
    \item Функция вывод - выполнение операций по выводу логических сигналов из слоя комбинационной схемы;
    \item Функция расширения пина - выполнение оперций по увеличению точек подключения к логическому сигналу.
\end{enumerate}
\subsubsection{Требования к организации входных и выходных данных}
Ввод данных в цифровое учебное устройство осуществляется с помощью механических переключателей, которые позволяют вручную задавать логические состояния входных сигналов. Для этого на плате предусмотрены:
\begin{enumerate}
    \item Тактовая кнопка для синхронизации работы схем;
    \item Набор DIP-переключателей для установки входных значений;
    \item Все входные сигналы проходят через схему подавления дребезга контактов.
\end{enumerate}

Вывод данных реализован через светодиодную индикацию: отдельные светодиоды отображают состояние каждого выходного сигнала.

\subsubsection{Требования к временным характеристикам}
Максимальное время отклика системы 1 секунд.
\subsubsection{Требования к надежности}
Вероятность безотказной работы устройства должна составлять не менее 99.99\% при условии
исправности источника питания.
\subsubsection{Требования к обеспечению надежного функционирования
системы}
Надежное функционирование устройства должно быть обеспечено выполнением со стороны заказчика совокупности организационно-технических мероприятий, перечень которых приведен ниже:
\begin{enumerate}
    \item Обеспечение устройства надежным источником питания на 5В;
    \item Очистка контактов (1 раз в семестр);
    \item Проверка целостности соединений (1 раз в семестр).
\end{enumerate}


\subsubsection{Время восстановления после отказа}
Время восстановления после отказа, вызванного сбоем электропитания технических
средств (иными внешними факторами), не должно превышать 10 минут при условии соблюдения условий эксплуатации
технических средств.
Время восстановления после отказа, вызванного неисправностью технических средств, не должно превышать времени,
требуемого на устранение неисправностей технических средств.
\subsubsection{Условия эксплуатации}
\begin{enumerate}
    \item Относительная влажность: 30-80 процентов (без конденсата);
    \item Запрещена эксплуатация в запыленных/загазованных помещениях;
    \item Напряжение: 5В DC ±5 процентов;
    \item Размещение устройства на ровной непроводящей поверхности;
    \item Непрерывная работа: не более 8 часов;
    \item Рекомендуемые перерывы: 15 мин каждые 2 часа.
\end{enumerate}

\subsubsection{Климатические условия эксплуатации}
Специальные условия не требуются.

\subsubsection{Требования к видам обслуживания}
Система не требует проведения каких-либо видов обслуживания.

\subsubsection{Требования к численности и квалификации персонала}
Пользователь устройства должен обладать базовыми знаниями методического материала.

\subsubsection{Требования к составу и параметрам технических средств}
\begin{enumerate}
    \item Логические вентили И, ИЛИ, НЕ – не менее 2 элементов каждого типа;
    \item Элементы памяти - синхронные D-триггеры не менее 3 элементов;
    \item Тактовая кнопка с защитой от дребезга;
    \item DIP-переключатели с защитой от дребезга;
    \item Светодиодные индикаторы (зеленый) – не менее 3 элементов;
    \item Гребенчатые разъемы (шаг 2.54 мм) - кол-во совпадает с колличеством логических пинов у микросхем;
    \item Разъем внешнего питания.
\end{enumerate}

\subsubsection{Требования к аппаратной совместимости}
Устройство должно быть совместимо с лабораторным оборудованием через стандартные разъемы. Оно должно поддерживать уровни сигналов TTL/CMOS (0-5 В) и работать с источниками питания 5В. Конструкция платы должна предусматривать совместимость с макетными платами (шаг 2.54 мм) и стандартными крепежными решениями. Устройство должно соответствовать требованиям совместимости для работы в типовой учебной лаборатории.

\end{enumerate}
